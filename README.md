# 📝 Mini Blog Personnel - React

Un blog moderne et responsive développé avec React, permettant de créer, lire et gérer des articles de blog.

![Capture d'écran du blog](/screenshot/)

## ✨ Fonctionnalités

- **📖 Lecture d'articles** - Interface de lecture optimisée
- **✏️ Création d'articles** - Modal de rédaction intuitive
- **🔍 Recherche** - Recherche en temps réel dans le contenu
- **🏷️ Catégorisation** - Filtrage par catégories
- **💾 Persistance** - Sauvegarde automatique dans le localStorage
- **📱 Responsive** - Design adaptatif mobile/desktop
- **🎨 UI Moderne** - Interface utilisateur professionnelle

## 🚀 Technologies Utilisées

- **React 18** - Framework frontend
- **Vite** - Build tool et dev server
- **CSS3** - Styling moderne avec Grid/Flexbox
- **LocalStorage** - Persistance des données
- **Git** - Versionning du code

## 📋 Prérequis

- Node.js (version 14 ou supérieure)
- npm ou yarn
